# CLAUDE.md — alpacode-voucher (superseded)

This repository is the original standalone site of the referral program
«Segnala un amico» (voucher.alpacode.it). **The program now lives in
[alpacode-website](https://github.com/FrancescoCorbosiero/alpacode-website)**,
under `/voucher/` and `/voucher/nuova-attivita/`, with its API at
`POST /api/referral` — everything about it is in that repo's
`docs/voucher.md`, and its working context in its `CLAUDE.md` and
`docs/status.md`.

Don't develop here: make changes in alpacode-website. This repo is kept
for its history; whether to archive it, and to point voucher.alpacode.it
(if still online) at alpacode.it/voucher/, is an open decision listed in
alpacode-website's `docs/status.md`.
